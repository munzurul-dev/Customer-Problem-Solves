# Customer Support Dashboard

A modern and responsive customer support dashboard built with React and Tailwind CSS. This project helps manage customer support tickets through an intuitive and clean user interface.

## Features

- View all support tickets
- Add tickets to the working list
- Mark tickets as completed
- Remove completed tickets
- Responsive design for all devices
- Loading state with Suspense
- Toast notifications
- Modern dashboard UI

## Technologies Used

- React
- Tailwind CSS
- DaisyUI
- React Toastify
- JavaScript (ES6+)
